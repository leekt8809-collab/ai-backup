1. 서비스 소개

AI Backup Personal은 개인용 데이터 백업 및 복원을 위한 프로그램입니다.

2. Google 사용자 데이터 접근

본 프로그램은 Google Drive API를 이용하여 사용자가 승인한 백업 파일을 생성, 조회, 수정, 삭제 및 복원합니다.

3. 데이터 이용 목적

Google 사용자 데이터는 백업, 복원 및 데이터 무결성 검증 목적으로만 사용합니다.

4. 데이터 보호 및 저장

백업 파일의 내용과 이름은 로컬 환경에서 암호화한 후 Google Drive에 저장하도록 설계되어 있습니다. 인증 정보는 암호화된 로컬 설정 파일에서 관리합니다.

5. 데이터 공유

Google 사용자 데이터를 광고, 판매 또는 인공지능 모델 학습 목적으로 이용하지 않으며, 별도의 제3자에게 제공하지 않습니다.

6. 데이터 삭제 및 보유 기간

백업 데이터는 사용자가 삭제할 때까지 보관됩니다. 사용자는 Google Drive에서 백업 파일을 삭제하고 Google 계정 설정에서 앱의 접근 권한을 철회할 수 있습니다. 로컬 인증 정보도 직접 삭제할 수 있습니다.

7. Google API 정책 준수

본 프로그램의 Google API 사용자 데이터 이용 및 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수하도록 운영합니다.
